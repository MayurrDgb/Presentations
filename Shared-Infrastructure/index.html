EXECUTIVE SUMMARY
The strategic vision
MBE France wants to build a centralized digital infrastructure, hosted by Fortidia — first as a test environment for MBE France, then rolled out to other MBE DOCs across Europe and even across brands worldwide.
01
Not a local project. It's the foundation for a multi-brand, multi-country digital platform — built once, proven in France, then shared.
02
It hosts a few high-value tools. A brand-guidelines hub, an AI brief & content generator, and a franchise-development landing page.
03
Multilingual, country-agnostic. Any DOC can use each tool in its own language — without rebuilding it.
04
The ask is modest. Three standard building blocks: a small server, an automated deploy pipeline, and secure domain routing.
Build once.
Share across Europe
and beyond.

WHAT WE NEED FROM FORTIDIA
Three standard building blocks
All three are common, well-understood infrastructure. Nothing exotic — and everything starts small.
🖥️
REQUIREMENT 01
A VPS
A small instance to start, scalable.
a small private server to run the tools. We start tiny and add power only as more countries come on board — we pay for what we use.
🔄
REQUIREMENT 02
A CI/CD pipeline
GitHub → auto-deploy to the server.
when we update a tool, it deploys to the server automatically and safely — no manual file copying, fewer mistakes, faster fixes.
🔐
REQUIREMENT 03
Reverse proxy + SSL
Multiple domains/subdomains, automatic HTTPS.
one front door that sends each address (brand.…, partners.…) to the right tool, and keeps every one secure with automatic HTTPS.
